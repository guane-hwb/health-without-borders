# Statistics

The **Statistics** screen gives administrators an overview of brigade activity — patients, vaccines, and nationalities. Availability depends on your role.

---

## 1. Access and scope

- **Organization administrators** see the statistics for **their own organization**.
- **Super administrators** can see **all organizations**, or narrow the view to a single one using the organization dropdown.

You can switch the language (**ES / EN**) from the header.

---

## 2. Filter by period

Use the quick filter buttons to choose the time window:

- **All** — all available data.
- **This month** — the current month to date.
- **Last 20 days** — a rolling recent window.
- **Custom** — opens a calendar where you select a specific date range.

The figures and trends update to match the selected period, comparing it against the previous one where applicable.
