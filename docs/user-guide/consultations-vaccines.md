# Consultations & Vaccines

This page explains how to add clinical care — consultations and vaccines — to a patient's record.

---

## 1. Add a consultation

1. Open the patient's record (by [scanning the bracelet or searching](patient-records.md)), or use the summary screen right after registration.
2. Tap **Add consultation**.
3. Complete the consultation details and save.

---

## 2. Add a vaccine

1. From the same summary or record screen, tap **Add vaccine**.
2. Enter the vaccine information and save.

---

## 3. How the bracelet is updated

When you add a consultation or a vaccine, the bracelet is **marked as modified** so the new information is written back to the NFC chip and synchronized to the server. If you are offline, the change is stored locally and appears in the [pending-to-sync queue](sync-pending.md) until a connection is available.

**Note:** After adding care, use **Finish** to complete the encounter. Remember to write the bracelet if it is still marked as pending.
